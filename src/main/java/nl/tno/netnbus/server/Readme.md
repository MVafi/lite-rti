This folder contains relevant files for the server side of the application. Every federate has its own ServerReceiver running in a thread. These instances run server-side, where they are waiting for request for the respective federate that they belong to. Request are handled by the serverReceiver, where the serverReceiver will transport information to the serverContext. The serverContext keeps track of the state of the server, where it is able to respond to these rquests using the serverSender. The serverSender is a singular instance where the respective socket is provided in order to allow for communication back to the client federate.
